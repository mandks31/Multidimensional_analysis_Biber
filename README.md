Comparing Austen & Shelley Using Multidimensional Analysis
This Jupyter notebook performs a comparative stylistic analysis of two classic literary works—Jane Austen's Pride and Prejudice and Mary Shelley's Frankenstein—using Douglas Biber’s multidimensional framework.

Key Features
Data Processing: Merges and cleans multidimensional corpus datasets using Pandas.

Statistical Visualization: Generates annotated heatmap comparisons of Z-scores across Biber's 6 linguistic dimensions via Seaborn and Matplotlib.

Stylistic Insights: Explores contrasts in linguistic features, from Austen’s higher interactive/involved dimensions to Shelley’s heavier narrative and elaborated reference structures.
